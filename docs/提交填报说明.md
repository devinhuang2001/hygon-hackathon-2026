`source env.sh && python verify.py` 即可产出 `verify_result.json`。

**环境适配中值得写进报告的三个坑**

1. `vllm_hcu` 用绝对符号链接覆盖 `vllm` 模块，镜像解包后链接失效 → `ModuleNotFoundError: ...modular_kernel`
2. 镜像不含 `/opt/hyhal`（驱动用户态由平台注入）→ `get hyhal driver version error`
3. triton HCU 后端要求 `ROCM_PATH` 下有 `aillvm`，宿主 DTK 没有 → `HSACOError ... .amdgcn`，表现为 EngineCore 启动失败

另外两个「看起来像模型不支持、其实不是」的坑：

- `Qwen3-ASR-*-hf` 权重全量张量带 `model.` 前缀，vLLM 0.21 加载报 `no module or parameter named 'model'`，必须用非 hf 版
- 强制对齐模型必须 `--runner pooling` + `architectures` 覆盖 + `--max-model-len 8192`
